## Components deliberately NOT used

Studied for protocol understanding only; **no code taken**. Listed so the
boundary stays auditable.

| Component | License | Reason |
|---|---|---|
| `overtake/TelegramSwift` | GPL-2.0-or-later | Copyleft would force Nodogram's license and block App Store distribution |
| `telegramdesktop/tdesktop` | GPL-3.0 + OpenSSL exception | Same, plus wrong stack (C++/Qt) |
| `tgcalls` / `tg_owt` | BSD / Apache-2.0 / MIT mix | Only needed for call media; out of scope for v1 |
